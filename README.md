# 人设工坊 · dsh-persona-lab

> **本项目由 AI 协助制作。**
> 代码、文档与界面在人类指令下由 AI（DeepSeek Harness 的编码智能体）生成；人类负责方向、验收与最终判断。
> 请把它当作「一个可以改的起点」，而不是经过长期打磨的产品。

从 B站 的视频评论、视频内容（字幕）与弹幕里，学「一个人怎么说话、是个什么样的人」，按学习区隔离产出可移植的**人设词**。
只读公开内容，不读私信；只产出，不自动改写任何插件。

---

## 状态

实验性。核心链路（采集 → 提取 → 人设词 → 测试区）已经跑通并做过真机验证，但：

- 提炼质量取决于语料与模型，**不保证符合你的预期**
- 从评论/字幕里学「对话感」先天不足（素材不是对话）
- B站 接口会变，风控会挡

---

## 它做什么

- **学**：三个源——视频评论、视频内容（字幕优先，没字幕用简介）、弹幕。视频从「学习重点」搜索或推荐流随机发现（推荐流只是内容渠道，不是学习源）。同一段文本（去掉表情码与标点后）在本次与最近几次里只算一次。过三道闸（隔离文本、合规词表、PII 剥离）后才算样本。
- **提炼**：分两部分——说话方式（私聊 / 公开评论 / 弹幕 / 表情）、人物画像（性格 / 在意 / 讨厌 / 反应 / 底线）。用 DSH 当前模型（或你自填的 OpenAI 兼容 API）。
- **产出**：每区一份人设词，四样东西——正文、字段表、可直接粘的纯文本、SillyTavern 角色卡（JSON + PNG）。
- **测**：聊天测试区，拿人设词在 DSH 里演一段，看像不像。
- **告诉你**：只读扫描已装插件，列出哪些「有人设入口」，标 A（可粘）/ B（人格只能自己长）。

## 它不做什么

- 不自动写入任何插件的人设。
- 不碰别的插件的数据目录。
- 不发表评论、不发私信、不点赞。
- 不把学到的原文当人设词——只留说话方式，人名、UID、链接、事件全部剥离。

## 安装

这是 DSH profile 的插件，跟随 DSH 启动。

```powershell
# 1. 先关掉 DSH（运行中替换已加载的包会 EPERM）
# 2. 装进 profile
"<DSH>\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add "link:D:\deepseek\persona-lab"
# 3. 重启 DSH → 设置 → 人设工坊
```

或者面板装：设置 → 插件 → 从本地安装 → 选这个目录。

包名必须与 `cordis.patch.yml` 里的 `name` 一致：`dsh-persona-lab`。

---

## 第一次用

1. 打开 **设置 → 人设工坊**。
2. 首屏会列出**权限与风险**，点「我明白，同意」之前它什么都不做。
3. **扫码登录 B站**，或粘贴 Cookie（至少 `SESSDATA`）。
4. 「学习区」里默认有一个区（关键词 `dsh`、`DeepSeek Harness`，带播放量/时长下限）。点「立刻学一次」。
5. 学完去「人设词」看结果，可以复制纯文本、下载 JSON 或 PNG 卡。
6. 不满意就去「测试」演一段，用「记一条修正建议」把意见写回去，下次学习会带上。

## 参数（每个学习区独立）

| 参数 | 默认 | 说明 |
|---|---|---|
| 学习源 | 视频评论 / 视频内容 开，弹幕关 | 弹幕开了要自己配过滤词 |
| 一次学习总条数 | 1000（冷启动） | 后续增量建议 200 |
| 单次运行上限 | 10 分钟 | 到点就停，不硬跑 |
| 时间窗 | 关 | 开了就每天在窗内自动学一次 |
| 配额比例 | 评论 60 / 视频内容 40 / 弹幕 0 | 只分给三个学习源 |
| 内容来源 | 推荐流参与找视频（开） | **推荐流不是学习源**：只负责找到视频 |
| 学习重点 | 空 | 它就是搜索词：填什么学什么；留空则随机看 |
| 播放量/时长下限 | 默认区有，新建区无 | 新建区不填 = 不筛 |
| 隔离文本 | 空 | 一行一条，命中就永远不学 |

## 多模态（表情包 / 图片 / 语音）

三条线，三层开关，默认都开但**没有通道就自动跳过**：

| 层 | 做什么 |
|---|---|
| 识别 | 评论里的图片 → vision 接口给「画面 + 情绪」；语音 → STT 转文字 |
| 学习 | 识别结果作为第五类样本（`media`）进提炼，单独产出「表情与表达」一块 |
| 使用 | 人设词里写「什么情绪配什么表达」，但不代发——发图要目标 bot 自己有通道 |

通道在「设置 → 多模态通道」里填：Base URL + API Key + 模型名，图片和语音分开配。

- 图片走 OpenAI 兼容的 `chat/completions` + `image_url`
- 语音走 `/audio/transcriptions`（multipart）
- 留空 = 这一路跳过，文本学习照常
- **不保存原始图片或音频**，只存识别出的描述与文字
- 内容会发到你填的端点——选你信得过的服务

**两种删除键**（跟需求对齐）：

- 删**一条学习内容** → 自动写进隔离文本，以后不再学。
- 删**一次学习的日志** → 直接删，不留痕，也不写隔离文本。

## 数据在哪

```
$DSH_HOME/persona-lab/            # 缺省 ~/.dsh/persona-lab
├── config.json                   # 全局配置（API Key 只存本机）
├── credential.json               # B站 凭据（0600 / icacls 收紧）
└── zones/<id>/
    ├── zone.json                 # 区配置
    ├── isolate.txt               # 隔离文本
    ├── learned.json              # 已学过 id（去重）
    ├── history/<runId>.json      # 每次学习的日志
    ├── samples/<runId>.jsonl     # 每次的样本（一行一条）
    ├── persona/v<n>.json         # 人设词版本（写前快照上一版）
    └── chat/<runId>.json         # 测试记录
```

整个目录可以搬走；`DSH_HOME` 或插件配置里的 `root` 可改位置。

## 合规与边界

- **三道闸**：硬词表（违法/色情/广告/政治泛化标签）→ 隔离文本 → PII 剥离。全在样本进入学习**之前**跑。
- **PII 剥离**：链接、邮箱、手机号、证件号、@某人、BV 号、6 位以上数字，全换成占位符。人设词里不会出现具体的人。
- **模型输出二次清洗**：提炼结果再过一遍 `sanitizePersonaOutput`，宁可这次不产出，也不把半成品写进库。
- **平台风险**：抓评论/弹幕可能违反 B站 条款；高频请求有风控风险。本插件不做规避，风险由使用者承担。
- **凭据**：只写本机，权限收紧，界面只回显昵称与 UID，不回显 cookie。

## 兼容

- 需要 DSH 有 `webServer`、`pluginManager`（可选）、`llm`（可选）。`webServer` 缺失时插件不激活，不会半启动。
- 设置页走 `settings.section`，和 fish 系列同一个位置。
- 模型：默认用宿主 `ctx.llm` + 当前默认模型；宿主不可用时退回你填的 API Key。
- 扫码登录用 B站 passport 接口，二维码是本插件自带的零依赖编码器生成（已验证可扫）。

### 已知限制

- **只做了 B站**。QQ / 微信 / 贴吧 / 抖音是后续适配器，当前未实现。
- **单账号**。多学习区靠「学谁（UID 白名单）」隔离，不靠多账号。
- **角色卡 PNG 是纯渐变底图**，没有角色立绘；SillyTavern 会正确读取设定，但卡面不好看。
- 评论接口有 WBI 签名与 412 风控；被风控时这次学习会记 error 并跳过该源，不会硬刷。
- 弹幕默认关：它是噪声最大的源，开了建议先配隔离词。
